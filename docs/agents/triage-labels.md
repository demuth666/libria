# Label Triage

Skill berbicara dalam lima peran triage kanonik. Berkas ini memetakan peran tersebut ke string label yang dipakai di issue tracker repo ini.

| Label di mattpocock/skills | Label di tracker kami | Arti |
| -------------------------- | --------------------- | ---- |
| `needs-triage`             | `needs-triage`        | Maintainer perlu mengevaluasi issue ini |
| `needs-info`               | `needs-info`          | Menunggu informasi tambahan dari pelapor |
| `ready-for-agent`          | `ready-for-agent`     | Sudah spesifik, siap untuk agent AFK |
| `ready-for-human`          | `ready-for-human`     | Perlu implementasi oleh manusia |
| `wontfix`                  | `wontfix`             | Tidak akan dikerjakan |

Saat sebuah skill menyebut peran (misalnya "apply the AFK-ready triage label"), gunakan string label yang sesuai dari tabel ini.

Edit kolom "Label di tracker kami" agar cocok dengan kosakata yang benar-benar dipakai.
